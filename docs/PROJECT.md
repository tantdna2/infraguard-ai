# InfraGuard AI — Project Overview

InfraGuard AI is an AI Engineering project for detecting building surface defects in UAV imagery.

The project focuses on building a reliable, explainable, reproducible, and deployable Computer Vision system. The initial repository foundation targets Python 3.11 and uses the `src/infraguard` package layout.

Implementation milestones and scope are maintained in `ROADMAP.md`. Technical decisions, dataset information, and experiment records are maintained in the other documents in this directory.
